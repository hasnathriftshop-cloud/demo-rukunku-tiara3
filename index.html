📊 Database Google Sheets & Cloud Sync

Hubungkan RukunKu ke Google Sheets menggunakan Google Apps Script gratis. Data warga, kas, dan iuran akan tersimpan otomatis di Google Drive Anda dan dapat diakses bersamaan oleh pengurus RT melalui laptop maupun smartphone.

💡 Kolom Password di Google Sheets: Password warga tersimpan di sheet Warga (Kolom O). Jika kolom ini belum muncul di spreadsheet Anda, klik tombol "⬆️ Kirim Data Lokal ke Sheet" untuk memperbarui tabel Google Sheets secara otomatis.
Cara Cepat Mendapatkan URL Google Apps Script:
  1. Buka spreadsheet baru di sheets.new
  2. Buka menu Ekstensi > Apps Script
  3. Salin seluruh isi kode dari file google-apps-script/Code.gs lalu tempelkan.
  4. Klik tombol Deploy > New deployment, pilih jenis Web app.
  5. Ubah Who has access menjadi Anyone (Wajib agar bisa diakses aplikasi).
  6. Salin Web app URL (/exec) lalu tempelkan pada kolom input di atas.
